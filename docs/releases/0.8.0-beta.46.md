# 0.8.0-beta.46

Fix startup after installing beta.45 over an installation whose configuration
was already migrated to version 5 or 6. Configuration version 7 rolls those
settings forward into the restored direct-control format. Existing version-4
installations also migrate without removing their mappings or permissions.

The migration preserves remaining device mappings, meter identities, room
observations, and pool volume. For versions 5 and 6, direct battery and pool
control starts disabled pending setup review. Previous migration records of
deleted settings remain available, with obsolete request-interface instructions
replaced by references to missing settings that need attention.

Values deleted by an earlier migration cannot be reconstructed. Re-enter missing
pool switch mappings and other removed settings, or recover their values from a
backup. The pool setup editor accepts direct switch mappings again.

Install this beta and restart Home Assistant. Do not manually edit the saved
config-entry version. This migration does not modify controller journals or
operate equipment.
