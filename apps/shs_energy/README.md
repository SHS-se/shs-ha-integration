# SHS Energy

![SHS](icon.png)

Your energy plan, controller insights and system diagnostics, in a dedicated
Home Assistant app. Uses the existing SHS branding and opens through Home Assistant
Ingress, with an optional **SHS** sidebar entry.

The app owns SHS settings, planning, controller decisions and diagnostics. A thin
Home Assistant companion supplies readings, executes native commands and exposes
SHS entities. Routine app updates do not require a Home Assistant restart.
See **Documentation** for installation and coordinated companion upgrades.
